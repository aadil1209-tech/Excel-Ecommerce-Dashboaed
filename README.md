# 📊 E-Commerce Performance Dashboard (Amazon vs. Flipkart)

An interactive Microsoft Excel analytics dashboard comparing sales performance, rating metrics, pricing strategies, and fulfillment status across **Amazon** and **Flipkart**.

---

## 🎯 Project Overview
This project processes multi-platform e-commerce product data to segment customer engagement and pricing trends between **Men's** and **Women's** categories.

## 🛠️ Tools & Skills Used
- **Tool:** Microsoft Excel
- **Features Used:** Pivot Tables, Pivot Charts, Conditional Formatting, Data Cleaning, Slicers, Custom Formatting.

---

## 📈 Key Insights & Findings
- **Order / Rating Volume:** Flipkart displays significantly higher customer rating volume compared to Amazon.
- **Pricing Strategy:** Men's category products average higher prices than Women's products across both platforms.
- **Data Cleanup:** Standardized null values and removed `(blank)` categories for clean reporting.
